# Shop Ledger
Desktop app (Electron) for orders, stock, pricing, profit and margins. Data is stored locally on each machine.

    npm install     # once
    npm start       # run it
    npm test        # test the data layer
    npm run dist    # build a Windows installer into dist/

Before first release: put your GitHub username in `package.json` (`build.publish.owner`).
Everything about releasing, updating and supporting other people's machines is in docs/MAINTENANCE.md.
